# RTL 原始碼

| 檔案 | 說明 |
|---|---|
| `i2c_touch_config.v` | 手刻 I2C master 觸控驅動（位址 0x08、~1kHz、開漏 SCL + 時脈延伸、指標讀 + 每筆握手、座標解碼） |
| `TOUCH_DETECT.v` | 手指偵測：INT 線 + 可重觸發單擊延時（~150ms）去彈跳 |

> 頂層整合（camera.v 等）屬課程提供之框架，不在公開範圍；本 repo 只含作者原創模組。
> 介面與驅動細節見 [`../docs/觸控晶片_I2C介面規格書_逆向工程版.md`](../docs/觸控晶片_I2C介面規格書_逆向工程版.md)。
